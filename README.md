# Photo-Realistic-Rendering-Competition-
Photo realistic rendering competition for COMP4610/8610. 

## Compile Instructions
```
mkdir build
cd build
cmake
make ..
```

## Run Instructions

```
./RayTracing TASK_N spp diamondX diamondY diamondZ rotX rotY rotZ numLights lightX lightY lightZ
```

Sample Command

```
./RayTracing 2 256 350 0 250 -12 25 18 2 0 -5 0
```
